# Address Book in C

A menu-driven Address Book application developed using the C programming language.

This project allows users to manage contacts with features such as creating, searching, editing, deleting, listing, and saving contacts to a file.

## Features

- Create a new contact
- Search contacts by name, phone number, or email
- Edit existing contacts
- Delete contacts
- Display all contacts in a formatted table
- Save contacts to a text file
- Load previously saved contacts when the program starts
- Phone number validation
- Email validation
- Duplicate phone number prevention
- Duplicate email prevention
- Maximum contact limit of 100 contacts

## Technologies Used

- C Programming
- Structures
- File Handling
- String Handling
- Pointers
- Dynamic data validation
- Standard C Libraries
